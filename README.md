## How to use it:

Change to the directory to want to work in.\
Use the command: quarto use template SieurRicort/quarto_template\
Having all 3 files (.yml ; .css ; .qmd) is mandatory for it to work.\

## Tips and tricks

If you want to go next line with little spacing between the two 2 blank spaces then press enter (or the symbol `\`).\
If you want a bigger spacing leave a blank line between 2 lines of text.\
You can edit pretty much everything with your css file.\
